# Peregrino ⛪

**Tu fe te acompaña, dondequiera que estés.**

Peregrino es una plataforma web gratuita, sin registro, para encontrar iglesias católicas, capillas, horarios de misas y confesiones. Comienza en San Miguel, El Salvador, y se diseña para una futura expansión internacional.

## Funcionalidades previstas
- Buscar por iglesia, municipio o departamento.
- Ver misas y confesiones con fuente y fecha de verificación.
- Consultar teléfonos de secretaría confirmados y rutas en mapas.
- Explorar un croquis de los 14 departamentos y un mapa de iglesias.
- Acceder al Evangelio del día desde Vatican News.
- Usar la web desde el celular con modo claro y azul marino.

## Stack
React + TypeScript + Vite + Tailwind CSS (PWA); Python + FastAPI; PostgreSQL; Leaflet + OpenStreetMap.

## Principios
Acceso gratuito sin cuentas públicas. No inventar horarios, teléfonos ni coordenadas. Marcar datos pendientes de confirmar y facilitar contacto directo con las parroquias.
