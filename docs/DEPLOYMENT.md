# Publicación

Cloudflare Pages: conectar FredyFuness/Peregrino, seleccionar rama de desarrollo para vista previa y main para producción. Directorio raíz frontend, comando npm run build, salida dist, Node 22. No requiere API: el JSON público sirve de respaldo. Verificar compilación, rutas directas, búsqueda, filtros, enlaces y HTTPS antes de anunciar. Configurar dominio y Search Console tras obtener URL real. No publicar horarios sin fuente ni fotografías sin licencia.
